Get started

Connect your agent to Canon

Create an API key, add Canon's MCP server to your agent (Claude, OpenAI, Gemini, Cursor, VS Code or any MCP client), and it can read normalized, cited patient records. The same key works for the REST API.

1Your API key

Free to create. Reading records and the usage dashboard work right away.

Copy this key now. It is stored hashed on our side and won't be shown again. This browser remembers it so the snippets below and the usage dashboard work.
